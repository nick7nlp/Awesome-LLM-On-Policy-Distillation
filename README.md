## Scope and how to use the list

The central topic is research that improves, explains, or implements teacher-to-student transfer on states generated by a language-model student. Entries identify contributions to objectives, teacher targets, state selection, training, interaction, and evaluation. Using OPD in a task is not sufficient by itself. Related reward or preference methods appear only where a specific comparison helps explain OPD, and necessary background is listed separately.

Dates below denote first public release. Each entry links to its source paper; repository links identify associated implementations or resources. Unofficial reproductions are labeled, and a dash means no repository is listed. Individual papers state their experimental conditions and limitations.
